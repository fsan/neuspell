## Quick Start Guide

### 1. Basic Spelling Correction

```python
from neuspell import BertChecker

# Initialize and load model
checker = BertChecker()
checker.from_pretrained()

# Correct a sentence
corrected = checker.correct("This is a sentece with erors.")
print(corrected)  # "This is a sentence with errors."
```

### 2. Fine-tune BERT for Your Domain

```python
from neuspell import BertChecker

# Load pre-trained model
checker = BertChecker()
checker.from_pretrained()

# Fine-tune on your data
checker.finetune(
    clean_file="your_clean_sentences.txt",
    corrupt_file="your_corrupt_sentences.txt",
    data_dir="path/to/your/data",
    n_epochs=3
)

# Use the fine-tuned model
corrected = checker.correct("Your domain-specific text with erors.")
```

### 3. Use Different BERT Models

```python
from neuspell import BertChecker
from neuspell.seq_modeling.helpers import get_tokens, load_data

# Prepare data and vocabulary
train_data = load_data("data_dir", "clean.txt", "corrupt.txt")
vocab = get_tokens([item[0] for item in train_data])

# Initialize with DistilBERT
checker = BertChecker()
checker.from_huggingface(
    bert_pretrained_name_or_path="distilbert-base-cased",
    vocab=vocab
)

# Fine-tune
checker.finetune(
    clean_file="clean.txt",
    corrupt_file="corrupt.txt",
    data_dir="data_dir"
)
```

## Data Format

For fine-tuning, you need two text files:

**clean.txt** (correct sentences):
```
The quick brown fox jumps over the lazy dog.
Machine learning is fascinating and powerful.
Natural language processing helps computers understand text.
```

**corrupt.txt** (corresponding sentences with errors):
```
The quik brown fox jumps over the lasy dog.
Machien lerning is fascinatng and powerfull.
Natral langauge procesing helps computrs understand text.
```

## Tips for Success

1. **Data Quality**: Use high-quality, diverse training data
2. **Data Size**: Aim for 1000+ training examples for good results
3. **Validation**: Always use a validation set to monitor training
4. **Epochs**: Start with 2-3 epochs, adjust based on results
5. **GPU**: Use GPU for faster training when available

## Troubleshooting

### Common Issues

**Import Error**: Make sure neuspell is installed
```bash
pip install -e .
```

**CUDA Out of Memory**: Use CPU or reduce batch size
```python
checker = BertChecker(device="cpu")
```

**Model Download Issues**: Check internet connection

**File Not Found**: Ensure data files exist and paths are correct
